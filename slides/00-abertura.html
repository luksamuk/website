Setup Local

  • Vamos usar modelos locais no curso — via Ollama
  • Sem API key, sem cartão, sem limite de tokens
# Instalar (Linux/Mac):
curl -fsSL https://ollama.com/install.sh | sh

# Baixar o modelo do curso (~2GB):
ollama pull gemma4:e2b-it-qat

No Google Colab, o Ollama já vem pronto nos notebooks das aulas!

Ollama

  • Roda modelos localmente na sua máquina
  • Vamos usar o Gemma 4 E2B (QAT) hoje — roda até em notebook simples!
  • Sem internet, sem API, sem custo
ollama run gemma4:e2b-it-qat

kitty icat ./japanese.png && \
ollama run qwen3.5:4b "Transcreva o texto e depois traduza o texto para Português: ./japanese.jpg" --think=false

Open WebUI

  • Interface web local customizável
  • Conecta seus modelos e chaves de API
  • Roda localmente (para mim!)

No meu caso, uso apenas para Ollama.

LM Studio

  • Interface gráfica para modelos locais
  • Vamos ver o Gemma 4 E2B (roda em celular!)
  • Alternativa fácil para quem não quer terminal
  • Site: https://lmstudio.ai/

Sprachspiel no Terminal

  • Ferramenta que desenvolvi: um harness cognitivo para LLMs
  • Memória persistente, 50+ ferramentas, OCR, tradução
  • Interface simples no terminal
sprach ocr ./japanese.jpg | sprach translate :br

Vocês vão construir algo ligeiramente similar ao longo do curso.
