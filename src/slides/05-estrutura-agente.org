* O que é um agente?

Agente = LLM + *harness* (estrutura para conversar)

O LLM puro só responde uma pergunta. Um agente:

- Lembra da conversa (memória)
- Tem personalidade (instruções)
- Pode usar ferramentas (extensões — próxima aula!)

* 4 Componentes do Agente

1. *System Prompt* — quem o agente é
2. *Memória (Histórico)* — o que já foi dito
3. *Input* — a pergunta atual
4. *Output* — a resposta do modelo

* O harness na mão: Dicts e Funções

#+BEGIN_SRC python
def criar_agente(instrucoes, max_historico=20):
    return {
        "instrucoes": instrucoes,
        "historico": [],
        "max_historico": max_historico
    }
#+END_SRC

#+BEGIN_SRC python
def conversar(agente, mensagem):
    messages = [{"role": "system",
                  "content": agente["instrucoes"]}]
    for msg in agente["historico"][-agente["max_historico"]:]:
        messages.append(msg)
    messages.append({"role": "user",
                     "content": mensagem})
    # ... chama o LLM, salva no histórico, retorna resposta
#+END_SRC

* Por que estado separado?

Estado em dicionário = mais simples para iniciantes.

Funções puras são mais fáceis de testar e entender.

#+BEGIN_SRC python
agente = criar_agente("Você é educado.")
conversar(agente, "Oi!")             # histórico atualiza
conversar(agente, "Lembra de mim?")  # tem contexto
#+END_SRC

* O problema do histórico infinito

Se a conversa crescer demais, o prompt fica gigante.

*Solução:* limitar o histórico.

#+BEGIN_SRC python
# Pegar só as últimas N mensagens
for msg in agente["historico"][-agente["max_historico"]:]:
    ...
#+END_SRC

** E compactação?

#+ATTR_HTML: :style font-size:0.55em;
- Truncar funciona, mas *joga fora informação*
- Na prática: *compactação* — LLM resume o histórico antes de enviar
- Ajuda com *lost in the middle*: LLMs não recuperam bem info no meio do contexto ([[https://arxiv.org/abs/2307.03172][Liu et al., 2023]])
- Compactação precisa de ferramentas — fica pra outro dia

* ReAct: Pensar e Agir

#+ATTR_HTML: :style font-size:0.55em;
Agentes reais *pensam e agem* em ciclos ([[https://arxiv.org/abs/2210.03629][Yao et al., 2022]])

#+ATTR_HTML: :style font-size:0.55em;
#+BEGIN_SRC text
Input → Thought → Action → Observation → Thought → Answer
#+END_SRC

#+ATTR_HTML: :style font-size:0.55em;
Exemplo: "Quanto é 234 × 987 + 100?"

- *Thought:* Preciso multiplicar
- *Action:* calculadora[234 × 987]
- *Observation:* 230958
- *Thought:* Agora somo 100
- *Answer:* 231058

#+ATTR_HTML: :style font-size:0.55em;
Hoje: memória + instruções. Próxima aula: ferramentas!

* De Requests para LangChain

Montar mensagens na mão funciona, mas é repetitivo.

#+ATTR_HTML: :style font-size:0.55em;
| Com =requests= | Com LangChain |
|-----------------+---------------|
| Montar dict manual | =ChatPromptTemplate= |
| Gerenciar histórico manual | =InMemoryChatMessageHistory= |
| Chamar API e parsear | =ChatOpenAI= (endpoint OpenAI-compatible) |
| =[-N:]= manual | Configurável |

#+BEGIN_SRC python
cadeia = prompt | llm  # pipe = encadeia
resultado = cadeia.invoke({"pergunta": "Oi!"})
#+END_SRC
