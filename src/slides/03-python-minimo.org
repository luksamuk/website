* Listas e Dicionários

#+BEGIN_SRC python
# Lista: sequência ordenada
frutas = ["maçã", "banana", "laranja"]
frutas.append("uva")
frutas[0]    # "maçã"
frutas[-1]   # "uva"

# Dicionário: pares chave-valor
pessoa = {"nome": "João", "idade": 30}
pessoa["nome"]           # "João"
pessoa["idade"] = 31     # atualiza
pessoa["cidade"] = "BH"  # adiciona
#+END_SRC

* 🔑 A sacada: mensagens de LLM

Uma conversa com um modelo é *uma lista de dicionários*:

#+BEGIN_SRC python
mensagens = [
    {"role": "system",
     "content": "Você é um tutor de Python."},
    {"role": "user", "content": "O que é uma lista?"},
    {"role": "assistant",
     "content": "É uma coleção ordenada..."},
]
#+END_SRC

#+begin_quote
Listas + dicionários = 90% do que você precisa pra LLM.

* Funções

#+BEGIN_SRC python
def saudar(nome, saudacao="Olá"):
    return f"{saudacao}, {nome}!"

saudar("Maria")        # "Olá, Maria!"
saudar("João", "Oi")  # "Oi, João!"
#+END_SRC

* Funções com estado (sem classes!)

#+BEGIN_SRC python
chat = []
chat.append({"role": "system",
             "content": "Você é um tutor."})
chat.append({"role": "user",
             "content": "O que é uma lista?"})

# Estado explícito: a lista É o histórico
print(chat)
#+END_SRC

💡 *Sem classes* — menos complexidade, mais clareza.

* Loops

#+BEGIN_SRC python
# Iterar em lista
for fruta in frutas:
    print(fruta)

# Range
for i in range(5):
    print(i)  # 0, 1, 2, 3, 4

# While
count = 0
while count < 3:
    print(count)
    count += 1
#+END_SRC
