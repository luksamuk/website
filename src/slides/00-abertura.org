** Ollama

#+ATTR_REVEAL: :frag (appear)
- Roda modelos *localmente* na sua máquina
- Vamos usar o *Gemma 4 E2B (QAT)* hoje — roda até em notebook simples!
- Sem internet, sem API, sem custo

#+ATTR_REVEAL: :frag (appear)
#+BEGIN_SRC bash
ollama run gemma4:e2b-it-qat
#+END_SRC

#+END_SRC

** Sprachspiel no Terminal

#+ATTR_REVEAL: :frag (appear)
- Ferramenta que desenvolvi: um *harness cognitivo* para LLMs
- Memória persistente, 50+ ferramentas, OCR, tradução
- Interface simples no terminal

#+ATTR_REVEAL: :frag (appear)
#+BEGIN_SRC bash
sprach ocr ./japanese.jpg | sprach translate :br
#+END_SRC
