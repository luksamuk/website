llama-server \

  --fit on --fit-target 512 \
  --ctx-size 8192 \

* O padrão universal: =/v1/chat/completions=

#+BEGIN_SRC python
import requests
import json

response = requests.post(
    "http://localhost:12434/v1/chat/completions",
    json={
        "model": "lfm2.5-2.6b",
        "messages": [
            {"role": "system", "content": "..."},
            {"role": "user", "content": "O que é Python?"}
        ],
        "temperature": 0.7,
        "max_tokens": 8192
    }
)

response_dict = response.json()
print(json.dumps(response_dict, indent=2, sort_keys=True))
#+END_SRC

* Tratamento de Erros

#+ATTR_HTML: :style font-size:0.7em;
| Código | Significado | O que fazer |
|--------+-------------+-------------|
| ConnectionError | Servidor não existe | Subir o servidor! |
| 404 | Modelo não encontrado | Conferir em =/api/tags= |
| 429 | Rate limit | Aguardar e tentar |
| 500 | Erro do servidor | Conferir payload |

#+begin_quote
Erro clássico: esquecer de subir o servidor antes da requisição.
#+end_quote
